# 标题事实抽取(v5)

输入是一批商品(key + 英文或中文标题 + 类目路径,类目可为空)。
**只抽事实,不做判断、不估价格、不定成本档。**


| 字段 | 取值 | 规则 |
|---|---|---|
| `material` | 纺织布料 / 玻璃陶瓷 / 金属 / 塑料硅胶橡胶 / 木竹 / 纸 / 皮革 / 混合 / 未知 | 商品**主体**(占成本大头的那部分)的材质。配件或包装的材质不算(例:金属挂钩的窗帘环→金属)。标题写了材质→照标题。**标题没写材质时**:①该品类几乎总是同一种材质才按品类填——袜子/手套/帽子/围巾/衣物/毛绒玩具/挂绳织带/布袋/网兜→纺织布料;纸巾/餐巾纸/纸盒/卡纸→纸;②品牌本身有公认主材质的(如 Lenox=瓷器、Pyrex=玻璃)可按品牌填,**evidence 必须写「品牌常识:<品牌>=<材质>」**;③其余拿不准→未知 |
| `size_class` | 轻小 / 中大件 / 大件重货 / 未知 | 商品**整体**的体积重量档,阈值锚 FBA 尺寸段。判据优先级:①标题写明尺寸或重量→按数字判:最长边 ≥36 in(90 cm)**或** 重量 ≥20 lb(9 kg)→`大件重货`;最长边 18-36 in(45-90 cm)**或** 重量 5-20 lb(2.3-9 kg)→`中大件`;都低于此→`轻小`。②标题没数字但品类天然如此→按品类:家具本体/床垫/健身器械/整机家电/地毯 5x7 ft 以上/大型宠物笼→`大件重货`;大号收纳箱/置物架/猫爬架/儿童座椅/行李箱→`中大件`;③其余拿不准→`未知`(**不要**猜成轻小)。多件装按**一个购买单位整体**判(50 支牙间刷仍是轻小)。evidence 必须写清依据:引用尺寸/重量原文,或写「品类常识:<品类>」 |
| `powered` | true / false | 商品本身含电池、电机、电路、LED/灯珠、USB 供电、充电等**用电部件**才算 true。"Lightweight"、"Light Blue"、"Black Light"(紫外荧光颜料)、"Lighter"(打火机相关配件)等字面陷阱不算 |
| `fragile` | true / false | 主体是玻璃、陶瓷、水晶、镜面等易碎材质才 true |
| `kit` | true / false | 一个单元里是**不同类东西的组合**(工具套装、维修零件包、派对套装、配件包、画具套装)→ true。**以下都是 false**:同类只是尺寸/颜色/型号不同的混装(已计入 pack_count);主商品附带的小配件(底座、挂钩、盖子、螺丝、保护壳、收纳袋、气泵、说明卡) |
| `pack_count` | 整数 | 一个购买单位里含几份**重复的单元**:同款 N 件→N("50 Pcs"→50,"3 Pack"→3,"Set of 4"→4,"2 Pairs"→2);同类不同尺寸/颜色/型号混装 N 件→N(如 "100 Pcs ... Multiple Sizes"→100,盖子 2+3+2+2→9);**N 套、每套含几样不同东西→N(套数)**(如 "50 Sets 螺栓+螺母+垫片"→50);只有 1 套不同零件的组合→1;单件→1。主商品附带的小配件不计件。多规格可选(如 "3/6/12 Pack")→填最小值 |
| `evidence` | 字符串 | 逐字引用支撑判断的标题片段,多段用 " / " 隔开;按品类常识判材质写「品类常识:<品类>」,按品牌判写「品牌常识:<品牌>=<材质>」 |
| `note` | 字符串 | 只在有歧义时写一句;kit=true 时必写"混装套装:<一个单元的构成>";无歧义写空串 |


## 输入

{INPUT}

## 输出

只输出一个 JSON 对象,不要任何别的文字、不要代码块标记。每个输入 key 一条:

{"<key>": {"material": "...", "size_class": "...", "powered": false, "fragile": false, "kit": false, "pack_count": 1, "evidence": "...", "note": ""}}
