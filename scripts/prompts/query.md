# 1688 搜索词(v1)

为每个需求写一个 1688 中文搜索词，用来在 1688 按名称搜货源。

规则：
- 用 1688 卖家标题里会出现的中文说法（"擦手纸"不写"洗手间纸巾"，"护理垫"不写"床单"时要看需求本身是什么）。
- 带上**区分款式的关键词**：适配车型/机型写全（"焕新版 Model Y""Rivian R1S""Pyrex 7201"），关键材质或结构（"不锈钢""无纺布""磁吸"）。
- **不要**带件数、装数、"批发"、"跨境"、英寸数字这类会把结果搜窄或搜偏的词。
- 3~5 个词，空格分隔，总长不超过 20 个字。
